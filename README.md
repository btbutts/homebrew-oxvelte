# Btbutts Oxvelte

## How do I install these formulae?

`brew install btbutts/oxvelte/<formula>`

Or `brew tap btbutts/oxvelte` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "btbutts/oxvelte"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
